Model

Project site, not user site

The repo name drives the URL, so this project publishes at /whoa/ without mixing new files into the main user-site repository.

Root

Static front door

Assets load through ./styles.css and ./main.js, which keeps everything safe for Pages under a subpath.

Next

Room for the real app

If this grows into a full product, add it in a subdirectory such as web/ and leave the Pages root as the stable public entry point.

Experiment

Localized parody bulletin

A separate page can request browser geolocation and build a fictional sci-fi dispatch around the visitor's area without pretending to be real reporting.
